# Core Gameplay Loop

1. Gather biological resources
2. Expand territory or influence
3. Unlock evolutionary traits
4. Survive ecological pressure
5. Complete kingdom progression
6. Unlock new lifeform/kingdom
7. Discover symbiosis systems
8. Permanently alter the ecosystem
9. Restart stronger

---

# Example Progression

Plant Run
-> Unlock Fungi

-> Unlock Insect Pollination
-> Unlock Predator Ecosystems
