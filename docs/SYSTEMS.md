# Core Systems

## Resources

### Biomass
General-purpose growth resource.

### Nutrients
Used for upgrades and evolution.

### Sunlight
Primary plant energy source.

### Decay
Primary fungal fuel source.

### Spores
Used for fungal spread and infection.

### Population Pressure
Represents ecological imbalance.

---

# Territory System

Territory generates:
- resources
- influence
- passive bonuses

Control spreads through:
- roots
- mycelium
- colonies
- ecological dominance

---

# Evolution System

Traits should always involve tradeoffs.

Example:
- Thick Bark
  - +Defense
  - -Growth Speed

- Venom
  - +Damage
  - +Nutrient Cost

---

# Ecological Pressure

World events create tension:
- droughts
- infestations
- invasive species
- wildfires
- extinction waves

These create active gameplay moments.
