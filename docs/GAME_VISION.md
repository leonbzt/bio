# Game Vision

## Core Concept

A retro mobile bio-fantasy RPG where players evolve through the kingdoms of life, mastering ecological systems and symbiotic relationships across repeated evolutionary cycles.

The game combines:
- ecological progression
- asymmetric kingdom playstyles
- prestige/meta progression
- passive + active gameplay pacing
- interlocking biological systems

## Long-Term Fantasy

The player gradually experiences:
- evolution
- cooperation
- ecological succession
- symbiosis
- emergent complexity

Instead of traditional RPG classes, players inhabit ecological niches.

Examples:
- decomposer
- predator
- pollinator
- parasite
- colony organism
- symbiotic hybrid
