## Goal

Display the 6 stub resources (Protein, Cellulose, Chitin, Phosphate, Lifeforce, Pollination) in the HUD alongside existing resources (Biomass, Nutrients, Sunlight, Decay, Spores). Each renders **greyed-out** with a tooltip explaining its purpose and when it activates.

Players see "what's coming" without confusion about why their numbers don't change.

## Display rules

| Resource | Visible when | Color | Tooltip |
|---|---|---|---|
| Existing 5 (biomass, etc.) | Always (per kingdom — Phase 7 implementation) | Full color | n/a |
| Protein | Animal niches OR Carnivore plantae (when it lands) | Full color in animal runs, **greyed in plant runs** | "Protein — amino-acid biomass. Generated by carnivore plantae and animal predators. Coming online: animal runs (Phase 10), carnivore plantae (Phase 14)." |
| Cellulose | Plant niches | Full color in plant runs (its source), **greyed in animal runs as a consumable not yet wired** | "Cellulose — plant structural fiber. Consumed by animal herbivores. Coming online: Phase 14." |
| Chitin | Fungi niches AND animal niches | **Greyed** | "Chitin — fungal cell walls and arthropod exoskeleton. Coming online: Phase 14." |
| Phosphate | Mycorrhizal fungi | **Greyed** | "Phosphate — mineral nutrient, the currency of mycorrhizal exchange. Coming online: Phase 14." |
| Lifeforce | Predator animals AND parasitic niches | **Greyed** (visible in predator runs because the tick produces a trickle per brief 09) | "Lifeforce — stolen vital energy. Coming online: parasitic niches (Phase 14)." |
| Pollination | Pollinator-host plantae | **Greyed** always until Phase 14 | "Pollination — reproductive vector via insects. Coming online: Phase 14." |

The greying convention: text in the resource label is rendered with `modulate = Color(0.6, 0.6, 0.6, 1.0)` (or theme equivalent). The number value still updates if any code path writes to the resource.

### Add `scripts/ui/resource_label.gd` (or use existing helper)

Each resource label needs:
- Current value (updates on `EventBus.resource_changed`)
- Greyed-when-inactive logic
- Tooltip text

```gdscript
extends Label

@export var resource_id: StringName = &""
@export var tooltip_when_inactive: String = ""

# When current kingdom_id / niche_id makes this resource "active" (real gameplay
# value), render full color. Otherwise greyed.
@export var active_kingdoms: Array[StringName] = []
@export var active_niches: Array[StringName] = []


func _ready() -> void:
    EventBus.resource_changed.connect(_on_resource_changed)
    EventBus.run_started.connect(_on_run_started)
    EventBus.niche_changed.connect(_on_niche_changed)
    tooltip_text = tooltip_when_inactive
    _refresh_value()
    _refresh_activity()


func _on_resource_changed(id: StringName, _amount: float) -> void:
    if id != resource_id:
        return
    _refresh_value()


func _on_run_started(_kingdom: StringName) -> void:
    _refresh_activity()


func _on_niche_changed(_niche: StringName) -> void:
    _refresh_activity()


func _refresh_value() -> void:
    text = "%s: %.0f" % [_short_name(), ResourceLedger.get_amount(resource_id)]


func _refresh_activity() -> void:
    var is_active: bool = _compute_is_active()
    if is_active:
        modulate = Color(1, 1, 1, 1)
    else:
        modulate = Color(0.6, 0.6, 0.6, 1)


func _compute_is_active() -> bool:
    if not active_kingdoms.is_empty():
        if active_kingdoms.has(GameState.current_kingdom_id):
            return true
    if not active_niches.is_empty():
        if active_niches.has(GameState.current_niche_id):
            return true
    return false


func _short_name() -> String:
    return String(resource_id).capitalize()
```

In the scene, configure each stub label:

| Label | resource_id | active_kingdoms | active_niches | tooltip_when_inactive |
|---|---|---|---|---|
| ProteinLabel | `&"protein"` | `[&"animals"]` | `[&"carnivore_plantae"]` (when it lands) | "Protein — amino-acid biomass. Coming online: Phase 14." |
| CelluloseLabel | `&"cellulose"` | `[&"plantae"]` | `[]` | "Cellulose — plant structural fiber. Coming online: Phase 14." |
| ChitinLabel | `&"chitin"` | `[]` | `[]` | "Chitin — fungal cell walls and exoskeleton. Coming online: Phase 14." |
| PhosphateLabel | `&"phosphate"` | `[]` | `[]` | "Phosphate — mycorrhizal exchange currency. Coming online: Phase 14." |
| LifeforceLabel | `&"lifeforce"` | `[]` | `[&"predator"]` (matches brief 09's trickle) | "Lifeforce — stolen vital energy. Coming online: Phase 14." |
| PollinationLabel | `&"pollination"` | `[]` | `[]` | "Pollination — reproductive vector. Coming online: Phase 14." |

(Note: setting both Protein's active_kingdoms and active_niches means it activates in either. The current implementation OR's the two checks.)

## Acceptance criteria
- [ ] HUD shows 6 new resource labels.
- [ ] In a plantae photosynthesizer run: Biomass/Nutrients/Sunlight active, Cellulose active (sole plant resource active here), all others greyed.
- [ ] In a fungi decomposer run: Decay/Spores active, others greyed.
- [ ] In a Lichen run: plant + fungi resources active (because layered).
- [ ] In an animal herbivore run: Protein active (sole animal resource visibly ticking; Cellulose is greyed because animals consume it but the resource itself isn't player-owned in this kingdom).
- [ ] In an animal predator run: Protein + Lifeforce active.
- [ ] Long-press / hover any greyed label → tooltip text appears.
- [ ] Mobile 360×640: all resource labels fit (possibly on a 2-row grid if they don't fit one row).
